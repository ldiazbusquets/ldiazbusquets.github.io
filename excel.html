03 How it was made

One file, no installation.

The guide is a single HTML file with its own search, quiz, and drill engines written in JavaScript. It opens in any browser, works offline, and needs nothing installed, which makes it easy to share with classmates and colleagues.

Decisions along the way

  • Removed the progress tracker. It looked good and slowed people down. A reference should get you to the answer and out of the way.
  • Icons instead of emoji, and one consistent type system, so it reads like a professional tool.
  • Fixed a blur bug on phones that made the section menu unreadable, caused by a visual effect on the sidebar.
  • Every ratio carries a benchmark, because a number means little without something to compare it to.

Why I built it. Writing a formula down with its meaning and a benchmark is how I learned it properly. The guide is that habit, organized so someone else can use it.
